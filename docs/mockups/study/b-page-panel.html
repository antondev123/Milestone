Notes for the team — direction B

  • Optimises for fidelity and trust. The learner sees the book as printed: section number, Learning Objectives box, justified body, footnote 20, the "10 (1.4.1)" page marker. Audio on/off changes nothing on the page except the highlighter marks, so the page is a stable object the learner can point at and quote.
  • What it costs. A facsimile from the text layer is a re-typeset, not the PDF: line and page breaks will not match the real page 10 unless we ship page PNGs (an offline rasterise step that does not exist). Justified 15px on a 390px page needs hyphenation and still shows rivers. "Fit page" is CSS zoom; older Firefox ignores it.
  • Word tracking driver. ElevenLabs /v1/text-to-speech/{voice}/with-timestamps returns character offsets; map them onto the word spans of the leg's verbatim text (data/courses/pom/verbatim/). The client owns the sub-block word position; the server cursor stays block-level (segment → block → phase), so nothing in the engine changes.
  • "Read from here" and the checkpoint. "Read from here" is goto at block granularity plus a client-side word offset. The checkpoint fires at the leg boundary (end of page 10 here), which is the block's ask phase; MCQ grades locally, the open answer goes to the grader (~4 s, the button shows "Grading…").
  • "Ask about this" needs no new tool. The tapped sentence is passed as context to ask, which is already grounded on the toc and the segment text. Real text selection needs a selectionchange listener and our own popover instead of the OS menu; the tap chip here is the simulation.
  • Auto-scroll etiquette. After the learner scrolls, auto-scroll yields for 4 s; the pill's "Now reading" line keeps the position visible so the sentence is never lost. Tapping the pill text could scroll back to it (not built here).
  • Tablet is the same components. Drawer vs. right column and sheet vs. in-column checkpoint are layout only; the panel, chat, checkpoint and pill are one implementation.
  • Listen mode hand-off is a footer row in the assistant panel; because the cursor is server-owned, "Your place carries over" is already true at block granularity.
