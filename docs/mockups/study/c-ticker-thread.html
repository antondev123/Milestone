Notes for the team

Direction C — teleprompter ticker + assistant anchored to the passage

  • Optimises for a quiet page. The book is rendered as the book; all word-level motion lives in one 88px ink strip under the top bar, so the reading surface never flickers and you can glance at the ticker like a subtitle.
  • Ticker behaviour: the sentence fills in word by word (45% → 100%), long sentences teleprompt one line at a time so the spoken word is always on the last visible line, and the 4px gold bar is block progress, mirroring the engine's block cursor.
  • Costs: eyes travel between strip and page; on the page only a 3px gold rule marks the sentence, so someone reading along cannot see the word. 88px of height is gone while audio is on (audio off returns it).
  • Engine needs: ElevenLabs TTS with_timestamps character offsets, mapped client-side to word and sentence boundaries of the verbatim leg text. Cursor stays block-level on the server; sentence/word index is client state. Tap-to-jump seeks within the block's audio, or calls goto when it crosses a block.
  • Anchored threads are ask with the pinned sentence passed as extra context next to the segment text. Persist notes keyed by (segment, block, sentence) so they survive a switch to Listen mode; the "Questions" count in the top bar reads the same store.
  • Concept check is the existing answer tool: MCQ graded locally, open answer via the grader (real latency ~4 s; mock waits 1.5 s). "Finish leg 5" = next at phase done.
  • Audio off is just the verbatim leg from data/courses/pom/verbatim/ styled like the book. No page PNGs needed, no rasterise step.
